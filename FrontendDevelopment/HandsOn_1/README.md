# Hands-On 01: Vehicle Service Management System - Basic Structure 🚗🔧

> **Module 01** of the Frontend Development Mastery Series. This module focuses on establishing a clean HTML5 semantic skeleton and custom CSS styling for the Vehicle Service Portal landing page.

---

## 🎯 Objectives & Learning Outcomes

- Structure web pages using HTML5 semantic elements (`<header>`, `<nav>`, `<main>`, `<section>`, `<article>`, `<footer>`).
- Implement basic CSS styling, typography, resets, and layout structures.
- Apply reusable CSS classes for card elements and interactive buttons.
- Create a clean navigation bar and hero call-to-action section.

---

## 📁 File Structure

```
handson_01/
├── index.html   # Main HTML5 structure for the Vehicle Service Portal
└── styles.css   # Custom CSS styling rules and design tokens
```

---

## 💻 Tech Stack & Features

- **HTML5 Semantic Elements:** Uses `<header>`, `<nav>`, `<main>`, `<section>`, `<article>`, and `<footer>` for improved accessibility and document outline structure.
- **Vanilla CSS:**
  - Standard CSS Reset (`margin: 0`, `padding: 0`, `box-sizing: border-box`).
  - Dark header styling (`#1e293b`) with inline navigation links.
  - Centered Hero Banner section with Call-To-Action button.
  - Styled Maintenance Service Cards featuring badge styling for service duration.

---

## ⚡ How to Run

Since this module consists of static HTML and CSS:

1. Open `index.html` directly in any web browser (Chrome, Firefox, Edge, Safari).
2. Alternatively, use a local static server like VS Code **Live Server** extension or run:
   ```bash
   npx serve .
   ```
