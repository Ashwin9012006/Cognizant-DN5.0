# Hands-On 10: Microservices Architecture

> This hands-on demonstrates how a monolithic application can be divided into independent microservices communicating over HTTP.

---

## Objective

- Learn microservices architecture.
- Build independent services.
- Implement API Gateway.
- Handle service communication.

---

## Services

### Course Service

- Departments
- Courses

Port: **5001**

### Student Service

- Students
- Enrollments

Port: **5002**

### API Gateway

- Request Routing

Port: **5000**

---

## Features

- Service Separation
- API Gateway
- HTTP Communication
- Fault Tolerance

---

## Technologies Used

- Flask
- SQLite
- Requests

---

## Learning Outcome

Successfully implemented a simple microservices architecture with service-to-service communication and API Gateway routing.
