# Hands-On 5: Flask with SQLAlchemy ORM

> This hands-on integrates SQLAlchemy ORM with Flask to build a database-driven REST API.

---

## Objective

- Connect Flask with a database.
- Implement ORM models.
- Perform CRUD operations.
- Execute JOIN queries.

---

## Features

- SQLAlchemy ORM
- Flask-Migrate
- CRUD Operations
- Database Relationships
- Serialization

---

## Database Models

- Department
- Course
- Student
- Enrollment

---

## Verification

- Database creation
- CRUD operations
- JOIN queries
- Data persistence

---

## Technologies Used

- Flask
- SQLAlchemy
- SQLite
