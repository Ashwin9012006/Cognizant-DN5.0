# Vehicle Service Management System 🚗🔧
> **Frontend Development Mastery Repository** — A progressive, hands-on learning series demonstrating web development from core HTML/CSS fundamentals to advanced multi-framework architectures (React, Angular, Vue 3, Redux Toolkit, Pinia, RxJS).

---

## 📌 Project Overview

This repository contains a step-by-step implementation of a **Vehicle Service Management System / Vehicle Service Portal**, structured across 10 progressive hands-on modules (`handson_01` to `handson_10`).

The goal of this repository is to demonstrate how a real-world web application evolves from basic static markup to full-fledged Single Page Applications (SPAs) with state management, async REST API integration, accessibility, and modern frontend tooling.

---

## 🛠️ Technology Stack

- **Core Technologies:** HTML5, CSS3, JavaScript (ES6+), TypeScript
- **Frameworks & Libraries:** React 18, Angular, Vue 3
- **State Management:** Redux Toolkit, Pinia, RxJS Observables
- **Routing:** React Router v6, Vue Router, Angular Router
- **Build Tools:** Vite, Angular CLI
- **Standards & Best Practices:** WAI-ARIA Accessibility Guidelines, Mobile-First Responsive Design

## ⚡ Quick Start Guide

### Prerequisites
- Node.js (v18.0.0 or higher recommended)
- npm or yarn

### Running a Specific Module

#### For Vanilla Modules (`handson_01` to `handson_04`, `handson_09`):
Simply open `index.html` in your web browser, or run a local dev server (e.g., Live Server extension or `npx serve .`).

#### For Vite / React / Vue Modules (`handson_05`, `handson_06`, `handson_08`, `handson_10`):
```bash
# Navigate to the module directory
cd handson_05  # or handson_06, handson_08, handson_10

# Install dependencies
npm install

# Start development server
npm run dev
