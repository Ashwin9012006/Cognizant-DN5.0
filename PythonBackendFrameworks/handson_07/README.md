# Hands-On 7 - FastAPI CRUD, Background Tasks & OpenAPI

## Objective

This hands-on extends the FastAPI project by implementing complete CRUD operations, asynchronous background tasks, and OpenAPI documentation customization.

---

## Features

- Full CRUD APIs
- Background Tasks
- Swagger Documentation
- REST Status Codes
- OpenAPI Metadata

---

## CRUD Operations

- Create
- Read
- Update
- Delete

Implemented using REST standards.

---

## Background Tasks

Enrollment creation triggers an asynchronous confirmation email using FastAPI BackgroundTasks.

- Title

- Contact Information

- Response descriptions
